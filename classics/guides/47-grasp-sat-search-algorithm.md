# 导读 47｜GRASP：一种 SAT 搜索算法

J. P. Marques-Silva、K. A. Sakallah，1996，ICCAD。[IEEE 出版方记录与 DOI](https://doi.org/10.1109/ICCAD.1996.569607)。本清单选用会议原版，而非作者后来扩展的期刊论文。

## 为什么读

SAT 求解是逻辑综合、验证和测试生成的重要基础问题。GRASP 把冲突分析纳入回溯搜索，使求解器可以从冲突中学习，并跳回更早的决策层级，避免重复探索相似的失败路径。

## 核心思想

作者提出 GRASP（Generic seaRch Algorithm for the Satisfiability Problem），将多种搜索剪枝技术组织为统一框架。其关键机制是分析搜索冲突，确定冲突原因后执行非时间顺序回溯，并记录冲突原因，使后续搜索能提前阻止类似冲突再次发生；论文还利用冲突因果链识别解所需的赋值。作者在包括测试模式生成问题在内的一组基准上报告，冲突分析对若干代表性 SAT 实例类别有效。这里的摘要结果不能推广为所有实例都同幅提速。

## 对后续学习的作用

GRASP 展示了搜索算法从“遇错回退”发展到“从错误中学习”的思路。**IC 设计阅读延伸**：形式验证和逻辑综合可用 SAT 表述约束；读应用论文时应追踪变量、约束编码、冲突学习与实例类别，而非只比较单一求解时间。

## 阅读前置与思考题

前置概念：命题逻辑、CNF、回溯搜索、决策层级和冲突。阅读时画出冲突分析如何产生学习信息，以及为何能允许非时间顺序回溯。

思考题：若一个学习子句能避免当前冲突，却增加数据库开销，求解器应怎样决定保留多久？实例结构会怎样影响这项选择？

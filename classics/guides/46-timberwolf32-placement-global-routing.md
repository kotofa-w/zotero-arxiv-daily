# 导读 46｜TimberWolf3.2：标准单元布局与全局布线

Carl Sechen、Alberto L. Sangiovanni-Vincentelli，1986，DAC。[出版方记录与 DOI](https://doi.org/10.1109/DAC.1986.1586125)。下文依据 IEEE 题录摘要。

## 为什么读

标准单元物理设计需要同时安排单元位置、估算互连代价并满足布线资源约束。TimberWolf3.2 将布局优化和全局布线迭代结合，是早期自动布局工具的经典案例。

## 核心思想

摘要描述了三阶段流程：前两阶段使用模拟退火降低估计互连成本，第二阶段按需插入 feed-through 单元并再次优化；随后进行全局布线，估计所需布线轨道数；最后仅在能减少轨道需求时对布局做局部修改。摘要报告，作者在多个工业电路实验中得到 15%–75% 的面积节省。这个范围应保留其论文实验语境，不能视为所有设计都会达到的收益。

## 对后续学习的作用

论文展示物理设计中的目标不是单独缩短几何距离，而是把布局估计与后续布线资源连接起来。**IC 设计阅读延伸**：读现代 P&R 论文时，可问早期布局代价能否预测拥塞、何时反馈全局布线信息、最后指标如何定义；这些是用于分析后续流程的问题。

## 阅读前置与思考题

前置概念：标准单元、布局、全局布线、模拟退火、线长估计和布线轨道。阅读时把三个阶段分别对应到目标函数与反馈信息。

思考题：仅降低估计线长为什么可能仍导致布线困难？加入轨道需求反馈后，优化目标会如何改变？

# 导读 07｜LSTM：让长时依赖的误差信号得以传播

Sepp Hochreiter 与 Jürgen Schmidhuber，*Neural Computation* 9，1735–1780（1997）。[DOI](https://doi.org/10.1162/neco.1997.9.8.1735) · [作者公开 PDF](https://www.bioinf.jku.at/publications/older/2604.pdf)。

## 为什么读

普通循环网络沿时间反向传播时，早期输入对很久以后输出的影响可能因梯度衰减而难以学习。本文针对这一问题提出 Long Short-Term Memory，并在构造的序列任务中学习跨越超过 1000 个离散时间步的依赖（摘要、1、5 节）。

## 核心思想

原版 LSTM 在记忆单元中构造自连接的线性路径，作者称为 *constant error carousel*，使误差信号沿时间传播时避免每步都被小导数反复缩小。输入门控制何时写入信息，输出门控制何时让记忆影响其他单元；门通过乘法调节通路（3–4 节）。因此，记忆路径与可学习的读写控制共同解决“保留什么”和“何时使用”的问题。

论文在人工生成的长时滞任务上比较学习表现，并讨论噪声和门的作用（5–6 节）。超过 1000 步的结果属于这些实验条件，不等于任意自然语言、时间序列或芯片设计任务都可保持同样效果。**1997 年这篇原文的结构讨论输入门和输出门；不要把后来常见的 forget gate 写成它已有的门。**

## 对后续学习的作用

阅读后续循环网络和注意力模型时，可分别问：信息沿时间怎样保存、读写怎样控制、训练信号能否有效到达较早时刻。这样也能区分最初 LSTM 架构与后来的改型。

**IC 设计阅读延伸**：若处理设计流程日志、功耗轨迹或时序变化，长时依赖可能值得建模；本文只在其报告的序列任务中验证方法，没有给出 IC 数据实验。

## 阅读前置与思考题

前置概念：循环神经网络、反向传播、链式法则与梯度消失。建议先读摘要、3 节的误差路径和 4 节记忆单元，再看 5 节实验设置。

思考题：只有恒定误差路径却没有输入门，旧记忆会遇到什么干扰？输出门为什么有助于控制记忆对其他单元的影响？

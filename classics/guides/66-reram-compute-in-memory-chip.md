# 导读 66｜基于 RRAM 的计算存储芯片

Weier Wan 等，2022，Nature。正式题录：[DOI 10.1038/s41586-022-04992-8](https://doi.org/10.1038/s41586-022-04992-8)；出版方论文入口：[Nature](https://www.nature.com/articles/s41586-022-04992-8) · [出版方 PDF](https://www.nature.com/articles/s41586-022-04992-8.pdf)。事实依据为出版方摘要的 OpenAlex 转录，未核全文。

## 为什么读

存内计算研究要从交叉阵列的单次矩阵运算走向可编程、可测量的芯片系统。本文报告一款基于电阻式随机存取存储器（RRAM）的计算存储芯片，适合用来理解器件、阵列、外围电路和算法共同构成的实物系统。

## 核心思想

论文报告 NeuRRAM RRAM 计算存储芯片，通过算法、架构、电路到器件的跨层协同优化，兼顾核心重配置、能效和与 4-bit 权重量化软件模型可比的精度。摘要列出 MNIST、CIFAR-10、语音识别与贝叶斯图像恢复任务的结果；具体指标须按原文任务和测量条件阅读，不应外推到任意 RRAM 工艺或通用处理器。

## 对后续学习的作用

与 ISAAC、PRIME 及 Ielmini–Wong 综述连读，可从架构提案过渡到实物芯片报告，并检查理论模型与测量之间的差距。**IC 设计阅读延伸**：可提出把存内计算用于特定 EDA 内核的研究问题，但需另行验证数值精度、编程流程、可靠性和端到端收益；本文未声称解决这些 EDA 问题。

## 阅读前置与思考题

前置概念：RRAM 交叉阵列、电导映射、模拟乘加和芯片测量。思考：如何区分阵列级、芯片级和应用级能效？器件误差应由电路校准、算法鲁棒性还是两者共同承担？

# 导读 44｜改进网络划分的线性时间启发式

Charles M. Fiduccia、Robert M. Mattheyses，1982，DAC。[出版方记录与 DOI](https://doi.org/10.1109/DAC.1982.1585498)。下文依据 IEEE 收录摘要。

## 为什么读

网络划分把电路或图分到不同区域，同时尽量减少跨区连接并满足平衡约束。Fiduccia–Mattheyses 方法针对这一组合优化问题设计快速启发式，影响了后续 VLSI 分区算法。

## 核心思想

论文提出迭代式 min-cut 启发算法，每一轮的最坏计算时间随网络规模线性增长。算法每次在两个分区间移动一个单元，按分区总大小而非单元数量维持平衡；专门的数据结构用于快速筛选候选移动，并避免不必要的增益更新。作者指出实践中通常只需少量轮次，因此可以较快得到 min-cut 的近似解。它是启发式算法，不承诺全局最优。

## 对后续学习的作用

这篇论文展示算法设计如何围绕工程约束定制数据结构和局部搜索。**IC 设计阅读延伸**：用于网表划分时，需检查平衡约束、连接权重、增益计算和后续物理实现成本；不同设计中的结果不应直接套用论文摘要的复杂度主张。

## 阅读前置与思考题

前置概念：图划分、cut、平衡约束、局部搜索和复杂度。阅读时跟踪一次单元移动如何改变相邻网络的切割代价。

思考题：限制单元移动后，何种情况下局部最优可能与全局最优差距较大？怎样用多轮初始化或其他算法改善解质量？

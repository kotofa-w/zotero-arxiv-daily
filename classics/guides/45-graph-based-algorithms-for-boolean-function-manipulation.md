# 导读 45｜布尔函数操作的图算法

Randal E. Bryant，1986，*IEEE Transactions on Computers*。[出版方记录与 DOI](https://doi.org/10.1109/TC.1986.1676819)。该文提出有序二叉决策图（OBDD）表示及相应操作算法。

## 为什么读

逻辑综合和验证需要表示、比较并操作布尔函数。显式真值表会随变量数指数增长；Bryant 的图表示通过共享子结构，让许多实际函数能以较紧凑形式操作。

## 核心思想

作者用有向无环图表示布尔函数，并对决策变量顺序施加约束。论文承认最坏情况下表示规模仍可随参数指数增长；但对许多典型应用函数，图表示相对合理。论文给出的操作算法运行时间与参与运算的图规模成正比，因此效率取决于图是否过度膨胀。作者通过逻辑设计验证问题的实验展示方法可行性。变量排序会影响图大小，这是实际使用时必须留意的表示特性。

## 对后续学习的作用

本文把数据结构选择与逻辑问题的复杂性联系起来：算法的快慢不仅取决于操作，还取决于函数表示的图规模。**IC 设计阅读延伸**：形式验证、等价检查和逻辑综合可将其作为图表示思路的历史基础；具体现代工具的算法与性能仍需分别查证。

## 阅读前置与思考题

前置概念：布尔函数、决策树、有向无环图、逻辑综合和验证。可先观察一个函数的决策图，再改变变量顺序比较节点数量。

思考题：为什么相同布尔函数可能因变量排序得到规模差异很大的图？在验证流程中，怎样判断图膨胀会成为瓶颈？
